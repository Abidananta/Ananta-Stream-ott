Picture-in-Picture update
On Android 8.0 (API 26) and newer, pressing Home / minimizing the app attempts to enter Android Picture-in-Picture.
The PiP window uses a 16:9 aspect ratio.
Returning to the app restores the normal full-screen app view.
This source bundle uses GitHub Actions to generate the Android project and build the APK. Trigger the existing Build Ananta OTT APK workflow to produce the updated APK.
Note: PiP behavior depends on Android/device support. The archive contains the source and build workflow, not a prebuilt APK.

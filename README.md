# Ananta-Stream-ott

Ananta OTT rebuilt source scaffold
This scaffold uses the corrected Dart source available in the conversation and includes Android TV launcher visibility, internet permission, and optional touchscreen support.
Important
This is a reconstructed source scaffold, not a verified APK. Flutter/Android Gradle wrapper files and launcher icon resources are normally generated by the Flutter SDK. The source has not been compiled in this environment.
Build using Flutter SDK
Install Flutter and Android Studio / Android SDK.
From this directory, run `flutter create --platforms=android --org com.ananta.ott .` if Flutter reports missing generated Android project files. Review generated AndroidManifest.xml and retain the `LEANBACK_LAUNCHER` intent filter and cleartext setting shown in this scaffold.
Run `flutter pub get`.
Run `flutter build apk --release`.
APK should be at `build/app/outputs/flutter-apk/app-release.apk`.
The app includes HTTP stream support in the manifest because the configured PTV stream URL uses HTTP. Use only streams you are authorized to access.
